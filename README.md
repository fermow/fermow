### 🛠️ Building / especially proud of

- **[Celestial Desk `planner`](https://github.com/fermow/planner)** — a
  self-hosted productivity suite: deadlines, weekly planner, a proper Shamsi
  calendar, journal, boards, life goals, even a "favorite music" corner. Wrapped
  in a Starry Night UI, boots with one Docker command. This is what I actually
  reach for daily, which is the whole point.
- **[Fraud detection with Personalized PageRank `PPR`](https://github.com/fermow/PPR)** —
  "guilt by association" modeling on transaction graphs: a custom power-iteration
  engine, sparse-matrix optimizations, and a React network dashboard. My way of
  combining graph algorithms with frontend work in one project.
- **[Konkur AI `konkur_ai`](https://github.com/fermow/konkur_ai)** — a
  counseling-team platform for Iranian exams (students, counselors, parents):
  role-based dashboards, study tracking, wake-up monitoring, live chat, and an
  alerting engine that runs on Iran time with a 75% threshold. React + Express +
  Postgres + Socket.IO, tested and CI/CD'd.
- **[ML from scratch `learning-ml-by-building`](https://github.com/fermow/learning-ml-by-building)** —
  learning the way I wish more courses taught: implement linear regression by
  hand via NumPy, guided by failing tests instead of slides.
